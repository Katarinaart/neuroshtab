## ГОЛОС KATERINA ART

**Тон:** партнёрский, на равных. Эксперт который делится знанием, не учит.

**Разрешено:**
- Лёгкая ирония и самоирония
- Конкретные факты и цифры вместо абстракций
- Короткие предложения там где нужен ритм
- Мнение, даже если оно неудобное

**Запрещено категорически:**
- "Сегодня хочу поделиться...", "Это важно знать каждому..."
- Списки из 5+ пунктов с одинаковой структурой
- Слово "уникальный" без доказательства уникальности
- Мотивационные финалы ("верь в себя", "ты справишься")
- Клише: "в эпоху AI", "цифровой мир", "следующий уровень"
- Избыточные эмодзи (максимум 2-3 на пост, не в каждом предложении)

## PIPELINE ДЛЯ ЛЮБОГО КОНТЕНТА

```
Понять задачу → Hook → Тело → Финал → stop-slop фильтр → Готово
```

### 1. Понять задачу

Перед написанием — уточнить:
- Платформа (Telegram / Instagram / LinkedIn / email)
- Цель (охват / продажа / доверие / виральность)
- Есть ли конкретный факт, история или инсайт в основе?
- Есть ли CTA и какой?

Без этого — спросить. Не угадывать.

### 2. Hook — первые 1-2 строки

Hook останавливает скролл. Пишется последним, но стоит первым.

Рабочие паттерны (из viral-hooks skill):
- Провокационный вопрос, на который читатель не знает ответа
- Неожиданное утверждение с конкретной цифрой
- Противоречие с тем что "все знают"
- История начатая с середины действия, не с предыстории

Плохой hook: "Хочу рассказать вам о важном инструменте для бизнеса."
Хороший hook: "Я запустила проект без единого сотрудника. Он приносит сотни тысяч."

### 3. Тело

**Для Telegram-постов:** один инсайт — один пост. Не пытаться вместить всё.
Максимум 1500 символов если нет веской причины для длиннее.

**Для каруселей:** слайд 1 = hook. Каждый следующий слайд — один аргумент.
Последний слайд = вывод + CTA. Не повторять одно и то же разными словами.

**Для email/рассылок:** тема письма = hook поста. Первый абзац = зачем читать
дальше. Структура: проблема → инсайт → решение → CTA.

**Для лендинг-копи:** читается сверху вниз без обязательного чтения всего.
Каждый блок должен работать автономно. CTA повторяется минимум трижды.

### 4. Финал

Не заканчивать на "высокой ноте" в духе мотивашки. Заканчивать:
- Конкретным следующим шагом (CTA)
- Неожиданным выводом который переворачивает ожидание
- Вопросом к аудитории если нужна вовлечённость

### 5. stop-slop фильтр (ОБЯЗАТЕЛЬНО перед финальной версией)

Прогнать через принципы stop-slop:

**Проверить каждое предложение:**
- Это конкретно или это абстракция? → заменить абстракцию на факт
- Это сказал бы живой человек? → если нет, переписать
- Это уже было тысячу раз? → найти другой угол

**Banned phrases** (автозамена на конкретику):
- "в эпоху AI" → конкретный год или контекст
- "уникальная возможность" → описать чем именно уникальна
- "следующий уровень" → следующий уровень чего именно
- "я рада поделиться" → просто поделиться без предисловия
- "это важно" → почему важно, кому, в каком контексте

## ФОРМАТЫ ПО ПЛАТФОРМАМ

**Telegram-пост:**
```
[Hook — 1-2 строки, останавливает скролл]

[Тело — 3-7 абзацев, каждый = одна мысль]

[Финал — CTA или вопрос]
```

**Карусель (Instagram/Telegram):**
```
Слайд 1: Hook
Слайд 2-N: По одному аргументу/шагу/факту
Последний: Вывод + CTA
```

**Email:**
```
Тема: [как hook поста]
Превью: [первые 50 символов тела]
Тело: проблема → инсайт → решение → CTA
```

## ВИДЕО-КОНТЕНТ

Для Reels/Shorts — скрипт по структуре talking-head:

```
0-3 сек: Hook (вербальный + визуальный)
3-30 сек: Один инсайт, без лирики
30-45 сек: Доказательство или пример
45-60 сек: CTA
```

Если нужно видео через Seedance или Remotion — передать задачу с готовым
скриптом и описанием визуального ряда.
